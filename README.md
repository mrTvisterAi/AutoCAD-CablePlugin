# AutoCAD Cable Plugin

Плагин для **AutoCAD 2025** (.NET 8 / `net8.0-windows`): кабели на полилиниях, расчёты, отчёты, однолинейка, палитра свойств, **вкладка ленты «Кабель»**.

## Сборка

```bat
dotnet build AutoCAD-CablePlugin.sln -c Release -p:AutoCADDir="C:\Program Files\Autodesk\AutoCAD 2025"
```

Выход: `src\CablePlugin\bin\Release\net8.0-windows\` — скопируйте **все** DLL в одну папку и загрузите `CablePlugin.dll` через `NETLOAD`.

## После загрузки

- В ленте появляется вкладка **«Кабель»** (Данные / Справочники / Отчёты).
- Команда `CABLEPROPS` — палитра свойств при выделении полилинии.

## Исправленные проблемы (см. историю)

- Чтение JSON из Xrecord: склеиваются **все** чанки (свойства снова видны после повторного выбора).
- Масштаб и числа: точка и запятая (`0.1`, `0,01`).
- Способ прокладки: ComboBox в полном диалоге.
- Целевая платформа: **net8.0-windows**.
