# AutoCAD Cable Plugin

Плагин для AutoCAD (.NET / C#) для кабельных линий на основе полилиний: данные, расчёты, отчёты.

## Команды

### Данные и расчёты
| Команда | Описание |
|---------|----------|
| `CABLEATTACH` | Привязка данных (WPF) |
| `CABLEEDIT` | Редактирование линии |
| `CABLEDICT` | Таблица труб (марка+жилы+сечение → ∅) |
| `CABLEEXPORT` | Экспорт линий в Excel |
| `CABLEINFO` | Просмотр в командной строке |
| `CABLERECALC` | Пересчёт |
| `CABLEREMOVE` | Удаление данных |

### Отчёты (этап 4)
| Команда | Описание |
|---------|----------|
| `CABLEJOURNAL` | **Кабельный журнал** → Excel и/или таблица в чертеже |
| `CABLEBOM` | **Ведомость объёмов** (кабели + трубы/гофра) |
| `CABLEPANEL` | **Таблица щита** по полю «От», коэффициент спроса |

Для журнала / ведомости / щита запрашивается режим: **Excel** / **Чертёж** / **Оба**.

## Возможности

- Несколько участков прокладки на одной линии
- Автоподбор ∅ трубы по таблице чертежа
- Длина: масштаб, запас %, опуски, округление вверх
- Ток, ΔU% (упрощённо по ГОСТ Р 50571.5.52-2011 прил. G), подбор АВ
- Журнал, ведомость, щит с Kс

## Сборка

```bash
dotnet build AutoCAD-CablePlugin.sln -c Release -p:AutoCADDir="C:\Program Files\Autodesk\AutoCAD 2025"
dotnet test tests/CablePlugin.Tests/CablePlugin.Tests.csproj
```

`NETLOAD` → `CablePlugin.dll` (+ Core, Data, UI, ClosedXML и зависимости).
